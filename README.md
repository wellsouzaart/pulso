# Pulso

PWA pessoal — assistente de vida + criador de apps via OpenRouter.

## Deploy no Cloudflare Pages

1. Push para GitHub
2. No Cloudflare Pages: conectar repo, sem build command, output dir = `public`
3. Custom domain: `pulso.wellsouza.com.br`

## Uso

- Abre no celular → instala como PWA
- Cole sua chave OpenRouter (sk-or-...)
- Descreva um app → o Pulso gera e você abre na hora
